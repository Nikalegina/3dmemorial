# Asset policy

Runtime 3D assets are not committed here by default. This directory stores manifests and small fixtures only.

Allowed sources for production assets:
- internally created / owned assets;
- CC0 assets;
- CC BY assets when attribution and redistribution conditions are satisfied;
- commercial assets only when the license explicitly permits delivery inside a web application.

Rejected by default: unclear license, editorial-only, NC, ND, or any asset whose web redistribution terms are incompatible with the product.
